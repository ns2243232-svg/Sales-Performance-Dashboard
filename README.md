# Sales Performance Dashboard | Excel & Power BI

## Project Overview
This project focuses on analyzing sales data and presenting business performance through a Power BI dashboard. Excel is used for data preparation and analysis.

## Tools & Technologies
- Microsoft Excel
- Microsoft Power BI

## Project Objectives
- Analyze overall sales performance.
- Identify top-performing products and categories.
- Compare sales across regions.
- Present key performance indicators (KPIs) in a dashboard.

## Key Analysis
- Total Sales
- Product and Category Performance
- Regional Sales Analysis
- Sales Trends

## Files Included
- `Sales Dashboard.pbix` — Power BI dashboard file.

## How to View
1. Download `Sales Dashboard.pbix` from this repository.
2. Open it using Microsoft Power BI Desktop.

Data Analysis, Dashboard Development, Data Visualization, Business Reporting.
